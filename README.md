# Restaurant Bill Generator

A Python program that generates restaurant bills with automatic discount and tax calculations.

## Features
- Customer name validation
- Food item validation
- Subtotal calculation
- 10% discount on bills of Rs. 100 or more
- 13% tax calculation
- Final bill generation

## Concepts Used
- Variables
- User input
- If/else statements
- Nested conditions
- Arithmetic operations
- Input validation

## How to Run

```bash
py main.py
```
